## Overview

This program is a small-scale biological image analysis tool that processes low-quality microscope images and automatically detects and counts biological objects (e.g. bacteria or cells). More specifically, the program takes a microscope-style image as input, enhances the quality so objects are easier to see, applies image processing algorithms to isolate biological objects, draws boxes around the detected objects, counts how many objects were found, and then visually displays the results visually. Additionally, the original image is converted to grayscale and then enhanced (noise reduction) to allow for comparison and easier analysis. In short, the program converts a noisy biological image into structured data in the form of object locations and counts. 

This project is still a work in progress. It functions and completes the above tasks without issue, but additional supplemental features will be added to further add to the usefulness of this program.
